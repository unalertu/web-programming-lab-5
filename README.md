# Assignment 5

A simple product dashboard made with React and Vite.

## Run

```bash
cd assignment1
npm install
npm run dev
```

## Files

All app files are in `assignment1`.

- `src/App.jsx`: name input and show/hide button.
- `src/components/ProductList.jsx`: product list.
- `src/components/Product.jsx`: product title and price.
- `src/components/Card.jsx`: wrapper for the product content.
- `src/main.jsx`: starts the app.
- `src/style.css`: basic styles.

## Challenges

Keeping the input connected to state and passing props between components needed attention.
